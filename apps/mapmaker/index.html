      Animated ground 0

      Click to stamp, Alt-click to clear. The map records where; the frames and the rate live in shared config, so re-timing one is a config edit, not a map change.

      Make an animation

      Pick any tile in the palette on the left — any sheet — and press Add frame. Frames go in the order you add them; drag to reorder, × to remove. Repeat a frame to hold on it.

      Built-ins are editable: the first change forks one into an override that keeps its id, so every cell already stamped with it follows. Reset to built-in puts the original back. Use Duplicate when you want a second animation instead of a changed one.

      Changing an Id orphans every cell already stamped with the old one.

      Collision 0

      Sub-tile: each tile is 3×3 cells. Click a cell, Shift-click a whole tile, Alt-click to erase. This is added to the art's own collision — building silhouettes and shorelines are measured from the sprites and stay there.

      After saving, run pnpm collision so the server sees it too — its trap-guard refuses fences that would wall you in, and it can only do that if it knows what you painted.
